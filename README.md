
# 💼 Arghya Dutta - Personal Portfolio Website

This is a fully responsive and interactive **portfolio website** built using **HTML, CSS, JavaScript**, and libraries like **AOS**, **Font Awesome**, **Chart.js**, and **Three.js**.  
It showcases sections like About, Skills, Projects, Coding Profiles, Education, and Contact.

---

## 📌 Features

- 🎨 Smooth scroll and animations with AOS  
- 📊 Dynamic skill representation using Chart.js  
- 🌐 Live coding profile stats from GitHub, LeetCode, GFG, and CodeChef  
- 💻 Projects section with links and GitHub repos  
- 🧾 Responsive design for all devices  
- 🚀 Scroll-to-top button and sticky header  
- 🌈 Interactive 3D background with Three.js (stars)

---

## 🛠️ Technologies Used

- **HTML**: Structure of the website
- **CSS**: Styling and layout
- **JavaScript**: Interactivity and animations
- **AOS**: Scroll animations
- **Font Awesome**: Icons
- **Chart.js**: Graphs for skill representation
- **Three.js**: 3D background (stars)

## 🚀 Installation

To run the project locally, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/Arghya-Dutta1/portfolio.git
```

2. Navigate to the project folder:

```bash
cd portfolio
```

3. Open `index.html` in your browser to see the portfolio in action.

---

## 📈 Stats

The portfolio integrates live coding stats from:

- **GitHub**: Shows public repositories and followers
- **LeetCode**: Displays the number of problems solved
- **CodeChef**: Displays ratings and rank
- **GFG**: Shows problems solved
